# Leap Year Checker in Python

This project contains a simple Python program that checks whether a given year is a leap year or not.

## Description

The program accepts a year from the user and checks it using the leap-year rules:

- A year divisible by 400 is a leap year.
- A year divisible by 100 but not by 400 is not a leap year.
- A year divisible by 4 but not by 100 is a leap year.
- All other years are not leap years.
